02Fixed: pre-commit over-staging

git add -u restages every tracked modification in the whole repo, not just what the commit in front of you is about — a path-scoped or staged-hunks commit silently swallows unrelated working-tree changes into it. Fix: remember what was staged before the auto-fixers run, and restage only that.

First attempt used git diff --cached --name-only -z (NUL-separated, to be filename-safe) captured into a shell variable, then xargs -0. Rehearsed it before trusting it, and the rehearsal failed — silently. NUL bytes don't reliably survive being captured into a POSIX shell variable via $(...); the value gets corrupted with no error. Replaced with git add --pathspec-from-file=-, which reads the path list straight from a pipe and never puts it through a shell variable at all.

Verified, not just written. A real rehearsal: stage one file, leave a second file modified-but-unstaged, run a simulated auto-fixer that touches both files' working trees, then apply the fix. Result: the staged file's index picks up the auto-fixer's change; the unstaged file's index stays byte-identical to HEAD, even though its working tree was touched — exactly the isolation the fix is supposed to guarantee.

03Fixed: /tmp handoff files

explain-it finalize wrote its spec and rendered GFM to /tmp/ — shared machine-wide across all five sibling card repos, and gone the moment the session ends. Moved to docs/design-notes/.work/, gitignored, scoped to the repo the handoff is actually happening in.
