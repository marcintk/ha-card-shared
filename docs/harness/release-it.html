01

What it does

Not part of any single change's flow — it sits on top of a batch of merged PRs. Eleven steps, of which two (3 and 5) can eject work back through /design-it → /code-it → /ship-it and restart the sweep. It is tag-driven: pushing vX.Y.Z is what actually cuts the release, and CI produces it as a draft.

02

The shape of a run

Two of the sweep steps can eject work back through the whole pipeline and restart from step 2. Only a sweep that comes back empty reaches the version bump.

03

Why the bump is a PR, and the tag is not

The naive move — npm version on main — trips the same pre-commit guard as any other direct commit. The release path splits the bump (a commit, so: a PR) from the tag (not a commit, so: applied straight to main).

04

What it uses

One phase of the shared hook, the CI it hands off to, and — uniquely — the rest of the pipeline as a subroutine when the sweep turns something up.

05

How it addresses the task

The task is to cut a coherent, consumer-legible release from a batch of merged changes — without shipping latent problems or design debt, and without tripping the main-branch guard. Six choices do that work.

a Never autonomous

The only skill carrying an explicit "never trigger this on your own" rule. A release is a stated human decision, not something the model reaches for.

b Sweep before bump

A repo-wide correctness pass and a repo-wide deepening scan both have to come back empty before a version number moves. Findings aren't noted for later — they go back through the pipeline now, and the sweep restarts.

c The bump obeys the same rules as any change

It lands as a PR through pre-commit and CI, not forced onto main. --no-git-tag-version plus a branch is how npm version is made to comply.

d Tag-driven, draft-first

Pushing vX.Y.Z is the trigger; release.yml checks semver monotonicity and always produces a draft, so a human sees the notes and the built asset before anything is public.

e Notes written for the consumer, not from the log

"What's new" and "what you'll notice after npm install" in the consumer's words, with the one migration step spelled out — or "Nothing — drop-in." stated outright.

f Cadence matched to blast radius

Patch batches freely, minor after a few PRs, major the moment it merges. The bump size and the release timing are decided together, out loud.
